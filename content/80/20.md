# 🛠️ Ruta de Aprendizaje de Programación (80/20)

## ✅ Hábitos diarios
- [ ] Práctica diaria de programación
- [ ] Resolver al menos un problema difícil
- [ ] Debugging constante: analizar y corregir errores
- [ ] Leer código ajeno para aprender patrones
- [ ] Repetición: rehacer y mejorar soluciones
- [ ] Registrar progreso y errores para aprender de ellos

---

## Semana 1-2: Fundamentos esenciales
### Teoría mínima
- [ ] Variables y tipos de datos
- [ ] Operadores básicos (+, -, *, /, %, ==, !=, >, <)
- [ ] Condicionales (`if`, `else`, `elif`)
- [ ] Loops (`for`, `while`)
- [ ] Funciones básicas (definir, llamar, parámetros y retorno)
- [ ] Listas/arrays y diccionarios

### Ejercicios prácticos
- [ ] Imprimir tablas de multiplicar
- [ ] Contar elementos en una lista
- [ ] Crear una función que devuelva el máximo de tres números
- [ ] Iterar sobre una lista y filtrar elementos

### Mini proyecto
- [ ] Calculadora básica de consola

---

## Semana 3-4: Manejo de errores y archivos
### Teoría mínima
- [ ] Manejo de excepciones (`try`, `except`)
- [ ] Leer y escribir archivos (`open`, `read`, `write`)
- [ ] Librerías estándar útiles (math, random, datetime)

### Ejercicios prácticos
- [ ] Crear un programa que lea un archivo y cuente palabras
- [ ] Crear un programa que genere números aleatorios y calcule estadísticas
- [ ] Capturar errores de entrada del usuario

### Mini proyecto
- [ ] Lista de tareas (CRUD: crear, leer, actualizar, eliminar) en consola

---

## Semana 5-6: Estructuras intermedias y OOP
### Teoría mínima
- [ ] Clases y objetos
- [ ] Atributos y métodos
- [ ] Encapsulamiento básico
- [ ] Concepto de herencia simple

### Ejercicios prácticos
- [ ] Crear una clase `Persona` con nombre y edad
- [ ] Crear método que salude y muestre información
- [ ] Heredar de `Persona` para crear `Estudiante` o `Empleado`

### Mini proyecto
- [ ] Sistema de registro de estudiantes simple (en memoria)

---

## Semana 7+: Proyectos prácticos y mejora continua
### Mini proyectos sugeridos
- [ ] Juego simple (Adivina el número, Piedra-Papel-Tijera)
- [ ] Generador de contraseñas
- [ ] Script que automatice tareas repetitivas (renombrar archivos, organizar carpetas)
- [ ] Pequeña aplicación con menú de opciones (ej. lista de tareas avanzada)

### Mejora continua
- [ ] Refactorizar código antiguo para que sea más limpio
- [ ] Comparar tu solución con soluciones de otros
- [ ] Resolver problemas de dificultad creciente en plataformas como LeetCode, HackerRank o Codewars
- [ ] Registrar errores comunes y cómo los solucionaste

---

## Recursos de apoyo
- [ ] Documentación oficial del lenguaje
- [ ] Foros y comunidades (Stack Overflow, Reddit, Discord)
- [ ] Repositorios de proyectos abiertos en GitHub
- [ ] Tutoriales cortos y concretos (videos o artículos)
