# 🛠️ Checklist de Aprendizaje de Programación (80/20)
# 📌 Filosofía

> No aprender todo.  
> Aprender lo necesario para construir, practicar y mejorar constantemente.

La programación se aprende:
- resolviendo problemas
- creando proyectos
- equivocándose
- debuggeando
- repitiendo

cosas para hacer todos los dias

- teoría → entiendes conceptos
- ejercicios → desarrollas lógica
- proyectos → aprendes a construir
- debugging → aprendes a analizar
- leer código **AJENO**→ aprendes patrones y estructura
- repetir → automatizas habilidades

el aprendizaje fuerte viene de

dificultad + repetición + consistencia
## Fundamentos
- [ ] Variables y tipos de datos
- [ ] Operadores básicos (+, -, *, /, %, ==, !=, >, <)
- [ ] Condicionales (`if`, `else`, `elif`)
- [ ] Loops (`for`, `while`)
- [ ] Funciones (definir, llamar, parámetros, retorno)
- [ ] Listas / Arrays
- [ ] Diccionarios / Mapas
- [ ] Manejo básico de errores (`try`, `except`)

## Estructuras de Datos
- [ ] Pilas (stack)
- [ ] Colas (queue)
- [ ] Conjuntos (set)
- [ ] Diccionarios / Mapas avanzados
- [ ] Tuplas (si aplica en tu lenguaje)
- [ ] Manipulación básica de strings
- [ ] Operaciones con listas y arrays (añadir, eliminar, recorrer, filtrar)

## Entrada / Salida
- [ ] Leer y escribir archivos
- [ ] Entrada de usuario (`input`)
- [ ] Formateo de salida (print, concatenación, f-strings)

## Funciones Avanzadas
- [ ] Funciones con retorno múltiple
- [ ] Funciones recursivas
- [ ] Funciones lambda o anónimas
- [ ] Manejo de argumentos opcionales y por palabra clave

## Programación Orientada a Objetos (OOP)
- [ ] Clases y objetos
- [ ] Atributos y métodos
- [ ] Encapsulamiento
- [ ] Herencia
- [ ] Polimorfismo básico

## Librerías y Herramientas
- [ ] Librerías estándar útiles (math, random, datetime, os)
- [ ] Importar y usar módulos
- [ ] Manejo de dependencias (pip o equivalente)
- [ ] Depuración básica (debugging, print de variables, tracebacks)

## Proyectos y Práctica
- [ ] Calculadora simple
- [ ] Lista de tareas (CRUD)
- [ ] Juego sencillo (Adivina el número, Piedra-Papel-Tijera)
- [ ] Generador de contraseñas
- [ ] Script para automatizar tareas simples

## Mejora Continua
- [ ] Leer código de otros proyectos
- [ ] Refactorizar código propio
- [ ] Resolver problemas de dificultad creciente
- [ ] Registrar errores y soluciones
- [ ] Comparar soluciones y aprender patrones
