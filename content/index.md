# 🧠 Método 80/20 para Aprender Programación

## 🎯 Objetivo
Aprender programación de forma rápida, práctica y progresiva, enfocándose en lo más importante primero.

---

# 📌 Filosofía

> No aprender todo.  
> Aprender lo necesario para construir, practicar y mejorar constantemente.

La programación se aprende:
- resolviendo problemas
- creando proyectos
- equivocándose
- debuggeando
- repitiendo

---

# 🚀 Fases de Aprendizaje

## 🟢 Fase 1 — Fundamentos Rápidos (80/20)

Aprender únicamente lo esencial:

- Variables
- Tipos de datos
- Condicionales (`if`)
- Loops (`for`, `while`)
- Listas
- Funciones
- Diccionarios
- `input()` y `print()`
- Manejo básico de errores
- Leer errores del programa

---

## 🟡 Fase 2 — Crear Proyectos Pequeños

Construir cosas simples constantemente:

- Calculadora
- Conversor
- Mini juego
- Lista de tareas
- Generador de contraseñas
- Automatizaciones simples

---

## 🔵 Fase 3 — Aprender Según Necesidad

Aprender únicamente lo que el proyecto requiera.

Ejemplos:
- Guardar datos → JSON
- Interfaces → GUI
- Web → HTML/CSS
- Bases de datos → SQL

---

## 🟣 Fase 4 — Mejorar Proyectos Viejos

Volver a proyectos anteriores y:
- optimizarlos
- limpiarlos
- organizarlos mejor
- agregar nuevas funciones

---

## 🔴 Fase 5 — Leer Código Ajeno

Aprender observando cómo programan otros.

Objetivos:
- detectar patrones
- mejorar lógica
- aprender estructuras
- descubrir nuevas formas de resolver problemas

---

La programación desarrolla esas habilidades porque te obliga a usarlas constantemente.  
Pero también puedes entrenarlas de forma consciente por separado.

Por ejemplo:

- **descomposición de problemas** → dividir cualquier problema grande en partes pequeñas
- **pensamiento abstracto** → buscar patrones y reglas generales
- **paciencia analítica** → resistir la frustración y analizar paso a paso
- **aprendizaje técnico** → aprender sistemas complejos progresivamente

Si entrenas eso directamente, luego la programación se vuelve más fácil.
